OSRTOS
============

OSRTOS.COM is a website about open source real-time operating systems and open source embedded projects.

Most of the text is available under the Creative Commons Attribution-ShareAlike License. This includes the lessons in `src/content/lessons/`.

The files in `public/sim/` and `src/generated/sim/` are generated by the RTOS simulator export and are not covered by that license. They contain kernel source excerpts and code under their own licenses (see `public/sim/THIRD-PARTY-LICENSES.txt`). Do not edit them by hand.

OSRTOS.COM use [Astro](https://astro.build/) and [Markdown](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet) to manage contents.

Your contributions are always welcome! Fork this project or create an issue.
